📱 安装步骤(很简单,跟着做)
1
点上面的按钮下载下载完成后,手机顶部通知栏会提示"下载完成"
2
点通知栏里的安装包手机会弹出一个提示:是否允许安装未知来源应用,点「允许」
3
点「安装」,等它装完安装好后点「打开」就能用了
⚠️ 如果点安装包时提示「不允许安装」,是因为手机默认禁止安装非应用商店的软件。别慌,按下面的教程开一下权限就行 ↓
🔧 小米 / 红米:怎么允许安装

设置 → 更多设置 → 安全 → 更多安全设置 → 「安装外部来源应用」→ 找到「浏览器」或「文件管理」→ 打开允许。
如果用的是微信/QQ 收到的文件,把「微信」「QQ」的允许也打开。

🔧 华为 / 荣耀

设置 → 安全 → 更多安全设置 → 外部来源应用安装 → 找到浏览器/文件管理/微信 → 允许安装。

🔧 OPPO / vivo / 一加

设置 → 应用与权限 → 权限管理 → 右上角更多 → 特殊访问权限 → 安装未知应用 → 选择浏览器/文件管理 → 允许。

🔧 三星 / 其他安卓手机

基本都是:设置 → 应用 / 应用程序 → 特殊访问权限 → 安装未知应用 → 选择你下载用的浏览器或文件管理器 → 允许。
